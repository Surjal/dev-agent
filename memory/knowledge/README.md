# Knowledge Memory

Notes about developing the dev-agent plugin itself only. In a target project, the installed plugin
uses the user's Obsidian vault instead (`D:\obsidian\brain\Patterns.md` / `Gotchas.md`) — see
`docs/obsidian-memory.md`.

General, project-independent knowledge the agent has accumulated: reusable patterns, gotchas about
specific tools/frameworks, useful commands, things worth remembering across all projects.

One Markdown file per topic, named `<topic-slug>.md`.

Do not store credentials, tokens, API keys, or connection strings here.
